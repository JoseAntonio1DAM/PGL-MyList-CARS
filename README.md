# PGL-MyList-CARS

## ¿Qué hace esta aplicación de REACT-NATIVE?

Esta es una sencilla aplicación de recuento de react-native
que nos ayuda a hacer una lista del elemento que queramos añadir.
En mi caso son los coches, hay 5 categorías distintas, uno le aña-
de el precio, escribes el modelo y decides si marcarlo para calcu-
lar el precio, o no.
