# README DEL EJERCICIO UNO

- Para este ejercicio nos pide únicamente hacer la aplicación con una herramienta de diseño.
Es decir, una aplicación que sea 98 % parecida a lo que será al final de implementar el código.

## HERRAMIENTA UTILIZADA: FIGMA

La herramienta utilizada es figma una herramienta basada en la nube para diseño de interfaces de usuario (UI) y experiencia de usuario (UX).
Funciona directamente en el navegador (aunque también tiene una app de escritorio), y permite a varias personas trabajar simultáneamente en el mismo archivo, como si fuera un Google Docs de diseño...

![Imagen de pantalla principal de figma](assets/image.png)

Lo que hicimos fue diseñar las pantallas de las que estará compuesta nuestra aplicación, mostrando las listas 'llenas'. vacías, y el modal que nos da un formulario ocupando la pantalla para así crear un nuevo elemento. Que en el caso de esta app son los coches cons sus distintas categorías (clasicos, gt, deportivos, superdeportivos, entre otros...)
